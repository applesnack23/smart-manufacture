# 구매 부품 STEP (단순화 모델)

조립 모델에서 구매 부품의 자리 · 크기를 확인하기 위한 **직접 만든 단순화 모델**입니다.
상자와 원기둥으로만 만들었고, 치수는 일반적인 판매 부품의 대표 치수입니다. 실제 부품과 조금 다를 수 있으니 구멍 위치 · 단자 위치는 실물로 확인합니다.

| 파일 | 부품 | 원점 · 방향 |
|---|---|---|
| `L298N.step` | L298N 모터 드라이버 (43 × 43) | 기판 왼쪽 아래 모서리 아랫면 |
| `TCRT5000_module.step` | TCRT5000 센서 모듈 (32 × 14) | 기판 왼쪽 아래 모서리, 핀은 −X 쪽 |
| `Rocker_switch_KCD1.step` | 전원 스위치 (21 × 15) | 패널 앞면 중심 (z = 0), 몸통은 −Z |
| `DC-022B.step` | DC 잭 | 패널 앞면 중심 (z = 0) |
| `Fuse_holder_5x20.step` | 퓨즈 홀더 (5 × 20 퓨즈) | 패널 앞면 중심 (z = 0) |
| `RaspberryPi_Zero_v1.3.step` | 라즈베리파이 제로 v1.3 (65 × 30) | 기판 왼쪽 아래 모서리 아랫면 |
| `JGB37-520.step` | JGB37-520 기어드 모터 | 기어박스 앞면 중심, 출력축은 +X |

Fusion 에서 **삽입 → 데이터 업로드** 또는 **파일 → 열기** 로 불러온 뒤 조립 모델에 배치합니다.
